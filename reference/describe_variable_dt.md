# Description d'une variable rendue en DT

Description d'une variable rendue en DT

## Usage

``` r
describe_variable_dt(x, by = NULL, ..., caption = NULL)
```

## Arguments

- x:

  vecteur à décrire

- by:

  (optionnel) vecteur de même longueur, un bloc de colonnes par valeur

- caption:

  (optionnel) titre du tableau

## Value

datatable
